📜 Project Report — Activity-2 · Problem 1 · IMDb Sequential Text Prediction

Problem statement, approach, architecture, results, and how to reproduce.

1 · What this project is

Sequential text prediction on IMDb movie reviews: given a review as a word sequence, predict POSITIVE or NEGATIVE sentiment. It answers Activity-2 Problem 1 using the IMDB dataset choice, implementing all Required Implementation steps (collect → clean → tokenize → numericalize → pad → build/run RNN variants) and all Solutions 1–10.

2 · How it is made

Data: 50,000 real IMDb reviews (25k train / 25k test) via src/data_loader2.py with HF → Stanford → polarity fallbacks. Preprocessing (src/preprocess.py): lowercase, strip HTML, remove punctuation, tokenize, build 20k-word vocabulary (+PAD/UNK), encode, post-pad to length 200. Models: five recurrent nets built from scratch in NumPy with Adam — SimpleRNN, BiRNN, 2-layer Deep RNN, LSTM, GRU (src/rnn_*.py). Production head: TF-IDF + Logistic Regression served by src/inference.py for instant, high-accuracy predictions with word-evidence and an unrolled recurrence trace.
